### **Question 1**
* **Problem:** Divide: $28 \div 4$.
* **Answer:** **Choice A: The quotient is `7` with no remainder.**
* **Graph Equation:** `28 / 4 = 7`
* **The Rule:** Whole number division: $a \div b = q$ with remainder $r = 0$ when $a$ is an exact multiple of $b$.
* **Work:**
  $28 \div 4 = 7$ since $4 \times 7 = 28$. Remainder is $0$.

### **Question 11**
* **Problem:** Determine whether the second number is a factor of the first: $72, 14$. Is $14$ a factor of $72$?
* **Answer:** **Choice B: No, 14 is not a factor of 72.**
* **Graph Equation:** `72 = 14 * 5 + 2`
* **The Rule:** A number $d$ is a factor of $n$ if $n \div d$ has a remainder of $0$.
* **Work:**
  $72 \div 14 = 5$ with remainder $2$ ($14 \times 5 = 70$, $72 - 70 = 2$). Since the remainder is not $0$, $14$ is not a factor of $72$.

### **Question 12**
* **Problem:** Fill in the blanks to correctly complete the sentence: In algebra, the result of the division $(x^2 + 2x + 2) \div (x - 3)$ shown can be written $x^2 + 2x + 2 = (x - 3)(\text{\underline{?}}) + \text{\underline{?}}$.
* **Answer:** $x^2 + 2x + 2 = (x - 3)($**`x + 5`**$) +$ **`17`**
* **Graph Equation:** `(x^2 + 2x + 2) / (x - 3)`
* **The Rule:** Division algorithm for polynomials: $P(x) = D(x) \cdot Q(x) + R$.
* **Work:**
  Dividing $x^2 + 2x + 2$ by $x - 3$ gives quotient $x + 5$ and remainder $17$:
  $(x - 3)(x + 5) + 17 = x^2 + 2x - 15 + 17 = x^2 + 2x + 2$.

### **Question 17**
* **Problem:** Fill in the blank to correctly complete the sentence: Consider the function $f(x) = 4x^4 + 7x^3 + 5x^2 + 16x + 44 = (x - 1)(4x^3 + 11x^2 + 16x + 32) + 76$. By inspection, we can state that $f(1) = \text{\underline{?}}$.
* **Answer:** $f(1) =$ **`76`**
* **Graph Equation:** `4x^4 + 7x^3 + 5x^2 + 16x + 44; k = 1`
* **The Rule:** By the Remainder Theorem, substituting $x = 1$ into $f(x) = (x - 1)q(x) + r$ eliminates $(x - 1)q(x)$ to leave $f(1) = r$.
* **Work:**
  $f(1) = (1 - 1)(4(1)^3 + 11(1)^2 + 16(1) + 32) + 76 = 0 + 76 = 76$.

### **Question 19**
* **Problem:** Select the correct choice that completes the sentence below: Factoring is opposite of (1) \_\_\_\_\_\_\_.
* **Answer:** **Choice B: multiplying** (or (1) **`multiplying`**)
* **Graph Equation:** `f(x) = (x - 1)(x + 1)`
* **The Rule:** Factoring takes an expanded sum/difference of terms and writes it as a product; multiplying expands a product into a sum/difference of terms.
* **Work:**
  Multiplying and factoring are inverse operations: $(x + 2)(x + 3) \xrightarrow{\text{multiply}} x^2 + 5x + 6 \xrightarrow{\text{factor}} (x + 2)(x + 3)$.
