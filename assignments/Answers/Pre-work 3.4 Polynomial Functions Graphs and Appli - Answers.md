### **Question 1**
* **Problem:** Select the answers that best complete the given statements. The behavior of the graph of a polynomial function to the far left or the far right is called its (1) ________ behavior. It depends upon the (2) ________ term(s).
* **Answer:** **(1) `end`**, **(2) `leading`**
* **The Rule:** The Leading Coefficient Test states that the far-left and far-right (end) behavior of a polynomial is determined by its leading term $a_n x^n$.
* **Work:** As $|x| \to \infty$, the highest-degree (leading) term dominates all lower-degree terms, determining the graph's end behavior.

---

### **Question 2**
* **Problem:** Fill in the blanks so that the resulting statement is true. The graph of $f(x) = x^3$ (1) ________ to the left and (2) ________ to the right.
* **Answer:** **(1) `falls`**, **(2) `rises`**
* **Graph Equation:** `f(x) = x^3`
* **The Rule:** An odd-degree polynomial with a positive leading coefficient falls to the left ($x \to -\infty \implies f(x) \to -\infty$) and rises to the right ($x \to \infty \implies f(x) \to \infty$).
* **Work:** For $f(x) = x^3$, the degree $3$ is odd and the leading coefficient $1$ is positive, so it falls to the left and rises to the right.

### **Question 3**
* **Problem:** Select the answer that best completes the given statement. The graph of $f(x) = -x^3$ (1) ________.
* **Answer:** **`rises to the left and falls to the right.`**
* **Graph Equation:** `f(x) = -x^3`
* **The Rule:** An odd-degree polynomial with a negative leading coefficient rises to the left and falls to the right.
* **Work:** As $x \to -\infty$, $-x^3 \to +\infty$ (rises left); as $x \to +\infty$, $-x^3 \to -\infty$ (falls right).

### **Question 6**
* **Problem:** Indicate whether the following statement is true or false. Odd-degree polynomial functions have graphs with opposite behavior at each end. The statement is (1) ________.
* **Answer:** **`true.`**
* **The Rule:** For odd $n$, $(-x)^n = -x^n$, so $f(x)$ approaches opposite infinities as $x \to -\infty$ and $x \to +\infty$.
* **Work:** One end always rises while the other end falls, so the statement is `true.`.

---

### **Question 7**
* **Problem:** Determine whether the statement is true or false. Even-degree polynomial functions have graphs with the same behavior at each end.
* **Answer:** **`True`**
* **The Rule:** For even $n$, $(-x)^n = x^n$, so both ends either rise together ($a_n > 0$) or fall together ($a_n < 0$).
* **Work:** Because $x^n > 0$ for both large positive and large negative $x$ when $n$ is even, both ends behave the same (`True`).

### **Question 11**
* **Problem:** Fill in the blank so that the resulting statement is true. Every real zero of a polynomial function appears as a/an (1) ________ of the graph.
* **Answer:** **`x-intercept`**
* **The Rule:** A real number $r$ is a zero of $f(x)$ if and only if $f(r) = 0$, which means $(r, 0)$ is an $x$-intercept of the graph.
* **Work:** Real zeros correspond directly to $x$-intercepts.

### **Question 12**
* **Problem:** Fill in the blanks so that the resulting statement is true. If $r$ is a zero of even multiplicity, then the graph touches the $x$-axis and (1) ________ at $r$. If $r$ is a zero of odd multiplicity, then the graph (2) ________ the $x$-axis at $r$.
* **Answer:** **(1) `turns around`**, **(2) `crosses`**
* **The Rule:** At a root $r$ of multiplicity $m$: if $m$ is even, $f(x)$ does not change sign (touches and turns around); if $m$ is odd, $f(x)$ changes sign (crosses the $x$-axis).
* **Work:** Even powers preserve sign across $x = r$ (`turns around`), while odd powers reverse sign (`crosses`).

### **Question 13**

* **Answer:** **`find f(0).`**
* **The Rule:** Any point on the $y$-axis has $x = 0$, so the $y$-intercept is $(0, f(0))$.

### **Question 14**
* **Problem:** Find the $x$- and $y$-intercepts of $f(x) = (x + 2)(x - 6)(x + 6)$.
* **Answer:** **Choice A** (`x-intercepts: -2, -6, 6; y-intercept: -72`)
* **Graph Equation:** `f(x) = (x + 2)*(x - 6)*(x + 6)`
* **The Rule:** Set $f(x) = 0$ for $x$-intercepts; evaluate $f(0)$ for the $y$-intercept.
* **Work:**
  - $x$-intercepts: $(x + 2)(x - 6)(x + 6) = 0 \implies x = -2, 6, -6$.
  - $y$-intercept: $f(0) = (0 + 2)(0 - 6)(0 + 6) = (2)(-6)(6) = -72$.

### **Question 15**
* **Problem:** Find the $x$- and $y$-intercepts of $f(x) = (x + 1)(x - 2)(x - 1)^2$.
* **Answer:** **Choice D**
  * **x-intercepts:** **`-1, 1, 2`** &nbsp;*(or as coordinates: `(-1, 0), (1, 0), (2, 0)`)*
  * **y-intercept:** **`-2`** &nbsp;*(or as coordinate: `(0, -2)`)*
  * **Matching Option:** `x-intercepts: -1, 1, 2; y-intercept: -2`
* **Graph Equation:** `f(x) = (x + 1)*(x - 2)*(x - 1)^2`
* **The Rule:**
  - $x$-intercepts occur where $f(x) = 0$: set each factor to zero ($x + 1 = 0 \implies x = -1$; $x - 2 = 0 \implies x = 2$; $(x - 1)^2 = 0 \implies x = 1$).
  - $y$-intercept occurs at $x = 0$: evaluate $f(0) = (0 + 1)(0 - 2)(0 - 1)^2$.
* **Work:**
  1. $x$-intercepts:
     - Factor $x + 1 = 0 \implies x = -1$ (multiplicity $1$, graph crosses $x$-axis).
     - Factor $x - 2 = 0 \implies x = 2$ (multiplicity $1$, graph crosses $x$-axis).
     - Factor $(x - 1)^2 = 0 \implies x = 1$ (multiplicity $2$, graph touches $x$-axis and turns).
     - Distinct $x$-intercepts: **`-1, 1, 2`**.
  2. $y$-intercept:
     - $f(0) = (1)(-2)(-1)^2 = (1)(-2)(1) = -2$.
     - $y$-intercept: **`-2`** (Point: $(0, -2)$).
  3. Matches **Choice D**.

* **Answer:** **Choice A**
* **Graph Equation:** `f(x) = x^3 - 4*x^2 - 4*x + 16`
* **The Rule:** Use end behavior, $y$-intercept, and factored $x$-intercepts to match the graph.
