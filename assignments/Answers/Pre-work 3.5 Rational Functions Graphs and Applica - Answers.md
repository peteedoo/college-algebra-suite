### **Question 1**
* **Problem:** Fill in the blank so that the resulting statement is true. All rational functions can be expressed as $f(x) = \frac{p(x)}{q(x)}$, where $p$ and $q$ are (1) ________ functions and $q(x) \neq 0$.
* **Answer:** **(1) `polynomial`**
* **The Rule:** By definition, a rational function is any function that can be written as the quotient of two polynomial functions $p(x)$ and $q(x)$, where the denominator $q(x)$ is not the zero polynomial.
* **Work:**
  1. Identify the standard definition of a rational function: $f(x) = \frac{p(x)}{q(x)}$.
  2. Both the numerator $p(x)$ and denominator $q(x)$ must be **polynomial** functions with $q(x) \neq 0$.

### **Question 2**
* **Problem:** Determine whether the statement below is true or false. "The domain of every rational function is the set of all real numbers."
* **Answer:** **`False`**
* **The Rule:** The domain of a rational function $f(x) = \frac{p(x)}{q(x)}$ consists of all real numbers except those values of $x$ for which the denominator $q(x) = 0$.
* **Work:**
  1. Consider a simple rational function such as $f(x) = \frac{1}{x}$.
  2. At $x = 0$, the denominator is $0$, making $f(0)$ undefined.
  3. Thus, the domain of $f(x) = \frac{1}{x}$ is $(-\infty, 0) \cup (0, \infty)$, not all real numbers. The statement is **False**.

The example of each quotient is (3) ________ and (4) ________ respectively.
* **Answer:** **(1) `undefined`, (2) `0.`, (3) `1/0`, (4) `0/1`**

  2. Zero divided by any nonzero number equals **$0$** (for example, $\frac{0}{1} = 0$).

### **Question 6**
* **Problem:** What is the domain of $f(x) = \frac{1}{x}$? What is its range?
* **Answer:**
  * **Domain:** `(-\infty, 0) \cup (0, \infty)`
  * **Range:** `(-\infty, 0) \cup (0, \infty)`
* **Graph Equation:** `f(x) = 1/x`
* **The Rule:** For the reciprocal function $f(x) = \frac{1}{x}$, neither $x$ nor $y = \frac{1}{x}$ can equal $0$.
* **Work:**
  1. **Domain:** Set the denominator not equal to zero: $x \neq 0$. In interval notation, $(-\infty, 0) \cup (0, \infty)$.
  2. **Range:** Since $\frac{1}{x}$ can take any nonzero real value but never equals $0$, the range is $(-\infty, 0) \cup (0, \infty)$.

### **Question 7**
* **Problem:** What is the largest open interval over which $f(x) = \frac{1}{x}$ increases, decreases, and is constant?
* **Answer:**
  * **Increases:** **Choice B (`None`)**
  * **Decreases:** **Choice A: The open interval(s) is/are `(-\infty, 0), (0, \infty)`**
  * **Constant:** **Choice B (`None`)**
* **Graph Equation:** `f(x) = 1/x`
* **The Rule:** As $x$ moves from left to right on each branch of $f(x) = \frac{1}{x}$, the function values strictly decrease.
* **Work:**
  1. On $(-\infty, 0)$, as $x$ increases toward $0^-$, $f(x) = \frac{1}{x}$ decreases from $0$ toward $-\infty$.
  2. On $(0, \infty)$, as $x$ increases toward $\infty$, $f(x) = \frac{1}{x}$ decreases from $+\infty$ toward $0$.
  3. Therefore, $f(x)$ never increases and is never constant; it decreases on $(-\infty, 0)$ and $(0, \infty)$.

### **Question 8**
* **Problem:** Is $f(x) = \frac{1}{x}$ an even or an odd function? What symmetry does its graph exhibit?
* **Answer:**
  * **Function Type:** **Choice B (`odd`)**
  * **Symmetry:** **`The graph of a function is symmetric with respect to the origin.`**
* **Graph Equation:** `f(x) = 1/x`
* **The Rule:** A function is odd if $f(-x) = -f(x)$ for all $x$ in its domain, which corresponds to symmetry with respect to the origin.
* **Work:**
  1. Evaluate $f(-x)$:
     $$f(-x) = \frac{1}{-x} = -\frac{1}{x} = -f(x)$$
  2. Since $f(-x) = -f(x)$, the function is **odd** and its graph is **symmetric with respect to the origin**.

### **Question 9**
* **Problem:** What is the domain of $f(x) = \frac{1}{x^2}$? What is its range?
* **Answer:**
  * **Domain:** `(-\infty, 0) \cup (0, \infty)`
  * **Range:** `(0, \infty)`
* **Graph Equation:** `f(x) = 1/(x^2)`
* **The Rule:** For $f(x) = \frac{1}{x^2}$, the denominator cannot be zero ($x \neq 0$), and the square of any nonzero real number is strictly positive ($x^2 > 0$).
* **Work:**
  1. **Domain:** $x^2 \neq 0 \implies x \neq 0$, giving $(-\infty, 0) \cup (0, \infty)$.
  2. **Range:** Since $x^2 > 0$ for all $x \neq 0$, $f(x) = \frac{1}{x^2} > 0$, giving $(0, \infty)$.

### **Question 11**
* **Problem:** Is $f(x) = \frac{1}{x^2}$ an even or an odd function? What symmetry does its graph exhibit?
* **Answer:**
  * **Function Type:** **`even`**
  * **Symmetry:** **`The graph of a function is symmetric with respect to the y-axis.`**
* **Graph Equation:** `f(x) = 1/(x^2)`
* **The Rule:** A function is even if $f(-x) = f(x)$ for all $x$ in its domain, which corresponds to symmetry with respect to the $y$-axis.
* **Work:**
  1. Evaluate $f(-x)$:
     $$f(-x) = \frac{1}{(-x)^2} = \frac{1}{x^2} = f(x)$$
  2. Since $f(-x) = f(x)$, the function is **even** and its graph is **symmetric with respect to the $y$-axis**.

### **Question 12**
* **Problem:** Fill in each blank with the correct response. The rational expression $\frac{x - 4}{x + 4}$ is undefined when $x$ is ____, so $x \neq$ ____. This rational expression is equal to $0$ when $x =$ ____.
* **Answer:**
  * **Blank 1 (undefined when $x$ is):** `-4`
  * **Blank 2 ($x \neq$):** `-4`
  * **Blank 3 (equal to $0$ when $x =$):** `4`
* **Graph Equation:** `f(x) = (x - 4)/(x + 4)`
* **The Rule:** A rational expression $\frac{p(x)}{q(x)}$ is undefined when its denominator $q(x) = 0$, and equals $0$ when its numerator $p(x) = 0$ (provided $q(x) \neq 0$).
* **Work:**
  1. Set the denominator equal to $0$: $x + 4 = 0 \implies x = -4$. Thus, it is undefined when $x$ is **$-4$**, so $x \neq -4$.
  2. Set the numerator equal to $0$: $x - 4 = 0 \implies x = 4$. Thus, the expression equals $0$ when $x = 4$.

### **Question 16**
* **Problem:** Find the domain of the following rational function: $h(x) = \frac{x + 6}{x^2 - 36}$
* **Answer:** **Choice A: The domain of $h(x)$ is restricted to `(-\infty, -6) \cup (-6, 6) \cup (6, \infty)`.**
* **Graph Equation:** `h(x) = (x + 6)/(x^2 - 36)`
