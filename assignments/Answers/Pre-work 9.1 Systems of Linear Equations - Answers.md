### **Question 1**
* **Problem:** Fill in the blank to correctly complete the sentence. The solution set of the following system is $\{(4, \text{____})\}$.
  $$\begin{aligned} -2x + 6y &= 28 \\ x + y &= 10 \end{aligned}$$
* **Answer:** **`6`** (The solution set is `{(4, 6)}`)
* **Graph Equation:** `-2x + 6y = 28; x + y = 10`
* **The Rule:** A point $(x, y)$ in the solution set satisfies both equations in the system. Substitute the given $x$-coordinate into either equation to find $y$.
* **Work:**
  1. Substitute $x = 4$ into the second equation $x + y = 10$:
     $$4 + y = 10 \implies y = 6$$
  2. Check in the first equation:
     $$-2(4) + 6(6) = -8 + 36 = 28 \quad \checkmark$$

### **Question 2**
* **Problem:** Fill in the blank to correctly complete the sentence. The solution set of the following system is $\{(\text{____}, 0)\}$.
  $$\begin{aligned} 4x + y &= 16 \\ 13x + y &= 52 \end{aligned}$$
* **Answer:** **`4`** (The solution set is `{(4, 0)}`)
* **Graph Equation:** `4x + y = 16; 13x + y = 52`
* **The Rule:** Substitute the known $y$-coordinate ($y = 0$) into either equation and solve for $x$.
* **Work:**
  1. Substitute $y = 0$ into the first equation $4x + y = 16$:
     $$4x + 0 = 16 \implies 4x = 16 \implies x = 4$$
  2. Check in the second equation:
     $$13(4) + 0 = 52 \quad \checkmark$$

### **Question 3**
* **Problem:** Fill in the blank to correctly complete the sentence. One way of solving the following system by elimination is to multiply equation (2) by the integer `____` to eliminate the $y$-terms by direct addition.
  $$\begin{aligned} 15x + 13y &= 85 \quad &(1) \\ 4x + y &= 14 \quad &(2) \end{aligned}$$
* **Answer:** **`-13`**
* **Graph Equation:** `15x + 13y = 85; 4x + y = 14`
* **The Rule:** To eliminate a variable by direct addition, the coefficients of that variable in the two equations must be additive inverses (opposites).
* **Work:**
  1. In equation (1), the coefficient of $y$ is $+13$.
  2. In equation (2), the coefficient of $y$ is $+1$.
  3. Multiply equation (2) by $-13$ so the $y$-term becomes $-13y$, which cancels $+13y$ when added directly.

### **Question 4**
* **Problem:** Select the correct choice that completes the sentence below. To solve the system
  $$\begin{aligned} 4x + y &= 5 \quad &(1) \\ 7x + 8y &= -10 \quad &(2) \end{aligned}$$
  by substitution, it is easiest to begin by solving equation (1) for the variable **(1)** `____` and then substituting into equation (2), because no fractions will appear in the algebraic work.
* **Answer:** **`y`** (Second radio button choice)
* **Graph Equation:** `4x + y = 5; 7x + 8y = -10`
* **The Rule:** When solving by substitution, isolate the variable that has a coefficient of $1$ or $-1$ to avoid introducing fractions.
* **Work:**
  1. In equation (1), $4x + y = 5$, the variable $y$ has a coefficient of $1$.
  2. Solving for $y$ directly gives $y = 5 - 4x$ with no fractions.

### **Question 5**
* **Problem:** Select the correct choice that completes the sentence below. If a system of linear equations in two variables has two graphs that coincide, there is/are **(1)** `____` solution(s) to the system.
* **Answer:** **`infinitely many`** (Second radio button choice)
* **The Rule:** Coinciding lines are the exact same line and share every point in common, resulting in infinitely many solutions.
* **Work:**
  1. Every point on the line satisfies both equations, so there are **infinitely many** solutions.

### **Question 6**
* **Problem:** Select the correct choice that completes the sentence below. If a system of linear equations in two variables has two graphs that are parallel lines, there is/are **(1)** `____` solution(s) to the system.
* **Answer:** **`no`** (Second radio button choice)
* **The Rule:** Parallel lines never intersect, so they share no common points and the system is inconsistent.
* **Work:**
  1. Because parallel lines have no points of intersection, there is **no** solution to the system.
