### **Question 1**
* **Problem:** Determine the number that can be used in place of the question mark to make the equation true: $7^? = 343$.
* **Answer:** **`3`**
* **The Rule:** Express $343$ as a power of $7$: $7^3 = 343$.
* **Work:**
  * $7^1 = 7$, $7^2 = 49$, $7^3 = 343$. Thus, $? = 3$.

### **Question 2**
* **Problem:** Determine the number that can be used in place of the question mark to make the equation true: $2^? = \frac{1}{8}$.
* **Answer:** **`-3`**
* **The Rule:** Use the negative exponent rule $\frac{1}{b^n} = b^{-n}$.
* **Work:**
  * $\frac{1}{8} = \frac{1}{2^3} = 2^{-3}$. Thus, $? = -3$.

### **Question 3**
* **Problem:** Determine the number that can be used in place of the question mark to make the equation true: $4^? = 2$.
* **Answer:** **`1/2`** (or `\frac{1}{2}`)
* **The Rule:** Since $\sqrt{4} = 2$ and $\sqrt{b} = b^{1/2}$, the exponent is $\frac{1}{2}$.
* **Work:**
  * $4^{1/2} = \sqrt{4} = 2$. Thus, $? = \frac{1}{2}$.

### **Question 4**
* **Problem:** Determine the number that can be used in place of the question mark to make the equation true: $\left(\frac{1}{3}\right)^? = 9$.
* **Answer:** **`-2`**
* **The Rule:** $\left(\frac{1}{b}\right)^{-n} = b^n$.
* **Work:**
  * $\frac{1}{3} = 3^{-1}$ and $9 = 3^2$, so $(3^{-1})^? = 3^2 \implies -? = 2 \implies ? = -2$.

### **Question 5**
* **Problem:** Solve the equation: $2^x = \frac{1}{16}$.
* **Answer:** **`Choice D: {-4}`**
* **The Rule:** Rewrite $\frac{1}{16}$ as a power of $2$ and equate exponents.
* **Work:**
  * $2^x = \frac{1}{2^4} = 2^{-4} \implies x = -4$ (**Choice D**).

### **Question 6**
* **Problem:** Solve the equation for $x$: $\left(\frac{1}{9}\right)^x = 81$.
* **Answer:** **`-2`**
* **The Rule:** Rewrite both sides with base $9$: $\frac{1}{9} = 9^{-1}$ and $81 = 9^2$.
* **Work:**
  * $(9^{-1})^x = 9^2 \implies 9^{-x} = 9^2 \implies -x = 2 \implies x = -2$.

---

### **Question 7**
* **Problem:** Solve the equation: $16^x = 4$.
* **Answer:** **`1/2`** (or `\frac{1}{2}`)
* **The Rule:** Rewrite $16$ as $4^2$ and equate exponents.
* **Work:**
  * $(4^2)^x = 4^1 \implies 4^{2x} = 4^1 \implies 2x = 1 \implies x = \frac{1}{2}$.

---

### **Question 8**
* **Problem:** State whether the following statement is true or false. Explain: "If $3^x = \frac{1}{27}$, then $x = -3$."
* **Answer:** **`Choice B: True, because solving the equation using the one-to-one property of exponential functions will result in x =` `-3`**
* **The Rule:** By the one-to-one property of exponential functions, $3^x = 3^{-3} \implies x = -3$.
* **Work:**
  * $3^x = \frac{1}{27} = \frac{1}{3^3} = 3^{-3} \implies x = -3$. The statement is **True** (**Choice B** with **`-3`**).

### **Question 11**
* **Problem:** Solve the following equation: $81^x = 3$.
* **Answer:** **`1/4`** (or `\frac{1}{4}`)
* **The Rule:** Rewrite $81$ as $3^4$ and equate exponents.

### **Question 12**

* **Answer:** **`-3`**
* **The Rule:** Rewrite both sides with base $4$: $\frac{1}{4} = 4^{-1}$ and $64 = 4^3$.

### **Question 13**
* **Problem:** Fill in the blank for the following statement. The inverse of an exponential function is (1) ________ function.
* **Answer:** **(1) `a logarithmic`**
* **The Rule:** By definition, the logarithmic function $f(x) = \log_b(x)$ is the inverse of the exponential function $g(x) = b^x$.
* **Work:**
  * Exponential and logarithmic functions are inverses of each other.

### **Question 14**
* **Problem:** Fill in the blanks. The function $f(x) = \log_b x$ is the (1) ________ function with base (2) ________.
* **Answer:** **(1) `logarithmic`, (2) `b.`**
* **Graph Equation:** `f(x) = ln(x) / ln(2)`
* **The Rule:** $f(x) = \log_b x$ is read as "the logarithmic function with base $b$."
* **Work:**
  * (1) **`logarithmic`**, (2) **`b.`**

### **Question 15**
* **Problem:** In both of the equations $a^y = x$ and $\log_a x = y$, $a$ is called the (1) ________.
* **Answer:** **(1) `base.`**
* **The Rule:** In both exponential form $a^y = x$ and logarithmic form $\log_a x = y$, $a$ is the base and $y$ is the exponent.
* **Work:**
  * $a$ is the **base.**

---

### **Question 16**
* **Problem:** Fill in the blank. The expression $\log_a x$ represents the (1) ________ to which the base $a$ must be raised to obtain $x$.
* **Answer:** **(1) `exponent`**
* **The Rule:** A logarithm is an exponent: $\log_a x = y \iff a^y = x$.
* **Work:**
  * $\log_a x$ is the **exponent** to which $a$ is raised to get $x$.

---

### **Question 17**
* **Problem:** Fill in the blank with the appropriate answer. A logarithm with base $e$ is called (1) ________.
* **Answer:** **(1) `a natural logarithm.`**
* **The Rule:** Base $e$ logarithms ($\log_e x = \ln x$) are called natural logarithms; base $10$ logarithms ($\log_{10} x = \log x$) are called common logarithms.
* **Work:**
  * Base $e$ is the natural base, so a logarithm with base $e$ is **a natural logarithm.**
