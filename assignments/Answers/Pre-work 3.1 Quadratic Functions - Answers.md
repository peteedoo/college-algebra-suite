### **Question 1**
* **Problem:** A polynomial function with leading term $3x^6$ has degree _______.
* **Answer:** **`6`**
* **The Rule:** The degree of a term $a x^n$ is the exponent $n$. For a polynomial in one variable, the degree is the highest exponent.

---

### **Question 2**
* **Problem:** The lowest point on the graph of a parabola that opens up is the (1) _______ of the parabola.
* **Answer:** **vertex**
* **The Rule:** 
  * If $a > 0$, the parabola opens **up** $\cup$, and the vertex is the **minimum (lowest point)**.
  * If $a < 0$, the parabola opens **down** $\cap$, and the vertex is the **maximum (highest point)**.

### **Question 3**
* **Problem:** The highest point on the graph of a parabola that opens down is the (1) _______ of the parabola.
* **Answer:** **vertex**

### **Question 4**
* **Problem:** The axis of symmetry of the graph of $f(x) = 6(x + 7)^2 - 4$ has equation $x =$ _______.
* **Answer:** **`-7`** (Equation: $x = -7$)
* **The Rule (Vertex Form):** For $f(x) = a(x - h)^2 + k$:
  * Vertex is $(h, k)$.
  * Axis of symmetry is always the vertical line: **$x = h$**.
* **Work:** Here $(x + 7) = (x - (-7))$, so $h = -7$. Thus, $x = -7$.
* **Pro-Tip:** Watch the sign! If you see $(x + 7)$, $h$ is $-7$, not $+7$.

### **Question 5**
* **Problem:** The vertex of the graph of $f(x) = x^2 + 18x + 5$ has x-coordinate _______.
* **Answer:** **`-9`**
* **The Rule (Standard Form):** For $f(x) = ax^2 + bx + c$:
  * The x-coordinate of the vertex is: **$x = -\frac{b}{2a}$**
* **Work:**
  $$a = 1, \quad b = 18, \quad c = 5$$
  $$x = -\frac{18}{2(1)} = -\frac{18}{2} = -9$$

### **Question 6**
* **Problem:** The graph of $f(x) = -3x^2 - 8x + 7$ opens down with y-intercept $(0, \underline{\ \ \ })$, so it has $\underline{\ \ \ }$ x-intercept(s).
* **Answers:**
  * y-intercept: **`7`** (Point $(0, 7)$)
  * Number of x-intercepts: **two**
* **The Rule:**
  1. **y-intercept:** Plug in $x = 0 \implies f(0) = c = 7$.
  2. **Number of x-intercepts:** 
     * Since the parabola opens down ($a = -3 < 0$) and its y-intercept $(0, 7)$ is *above* the x-axis ($y > 0$), the graph must cross the x-axis twice.
     * Alternatively, check the discriminant: $D = b^2 - 4ac = (-8)^2 - 4(-3)(7) = 64 + 84 = 148 > 0 \implies 2$ real x-intercepts.

### **Question 7**
* **Problem:** Match each equation with the description of its parabola:
  * $y = -(x + 4)^2 + 2$
  * $y = -(x + 2)^2 + 4$
  * $y = (x + 4)^2 + 2$
  * $y = (x + 2)^2 + 4$
* **Answers:**
  * (1) $y = -(x + 4)^2 + 2 \implies$ **vertex $(-4, 2)$, opens down**
  * (2) $y = -(x + 2)^2 + 4 \implies$ **vertex $(-2, 4)$, opens down**
  * (3) $y = (x + 4)^2 + 2 \implies$ **vertex $(-4, 2)$, opens up**
  * (4) $y = (x + 2)^2 + 4 \implies$ **vertex $(-2, 4)$, opens up**
* **The Rule:** In $y = a(x - h)^2 + k$, vertex is $(h, k)$. If $a$ is positive, it opens up; if negative, it opens down.

### **Question 8**
* **Problem:** Find the root: $\sqrt{\frac{9}{16}}$
* **Answer:** **A. $\sqrt{\frac{9}{16}} = \frac{3}{4}$**
* **The Rule:** Quotient rule for radicals: $\sqrt{\frac{a}{b}} = \frac{\sqrt{a}}{\sqrt{b}} = \frac{\sqrt{9}}{\sqrt{16}} = \frac{3}{4}$.

---

### **Question 9**
* **Problem:** Simplify the radical: $\sqrt{\frac{5}{36}}$
* **Answer:** **`\frac{\sqrt{5}}{6}`**
* **The Rule:** $\sqrt{\frac{5}{36}} = \frac{\sqrt{5}}{\sqrt{36}} = \frac{\sqrt{5}}{6}$.

### **Question 10**
* **Problem:** Which is the greatest perfect square factor of $112$?
* **Answer:** **D. 16**
* **Work:** List squares: $4, 9, 16, 25, 36, 49, 64 \dots$
  * $112 / 4 = 28$
  * $112 / 16 = 7$ (16 is a factor)
  * None of $36, 49, 64$ divide 112 evenly. Greatest perfect square factor is $16$.

### **Question 11**
* **Problem:** A student wrote $\sqrt{1875} = \sqrt{25 \cdot 75} = 5\sqrt{75}$. What went wrong? Give the correct simplified form.
* **Answers:**
  * Error description: **the greatest perfect square,**
  * Correct form: **`25\sqrt{3}`**
* **The Rule:** Always factor out the *largest* perfect square. $1875 = 625 \times 3$, and $\sqrt{625} = 25$. So $\sqrt{1875} = 25\sqrt{3}$.

### **Question 12**
* **Problem:** Simplify $\sqrt{48}$.
* **Answer:** **A. $\sqrt{48} = 4\sqrt{3}$**
* **Work:** Find largest square factor: $48 = 16 \times 3 \implies \sqrt{16 \cdot 3} = 4\sqrt{3}$.

### **Question 13**
* **Problem:** Simplify $\sqrt{176}$.
* **Answer:** **A. $\sqrt{176} = 4\sqrt{11}$**
* **Work:** $176 = 16 \times 11 \implies \sqrt{16 \cdot 11} = 4\sqrt{11}$.

### **Question 14**
* **Problem:** Simplify $-\sqrt{363}$.
* **Answer:** **A. $-\sqrt{363} = -11\sqrt{3}$**
* **Work:** $363 = 121 \times 3 \implies -\sqrt{121 \cdot 3} = -11\sqrt{3}$.

### **Question 15**
* **Problem:** Interactive Graphing Tool: Draw a solid vertical parabola overlaying the dashed parabola.
* **Answers:**
  * **First Point (Vertex):** **`(2, 1)`**
  * **Second Point on Parabola:** **`(0, 2)`** (or `(4, 2)`)
* **How to Read Any Parabola Graph:**
  1. Identify the turn-around point (vertex): $(2, 1)$.
  2. Follow the grid to an exact grid intersection: at $x = 0$, the curve passes through $(0, 2)$; at $x = 4$, through $(4, 2)$.
