### **Question 1**
* **Problem:** Evaluate $-2^2$
* **Answer:** **`-4`**
* **Explanation:** By order of operations, the exponent applies to the base $2$ first: $2^2 = 4$. Then apply the negative sign: $-(4) = -4$.

### **Question 2**
* **Problem:** What must be true about the value of the variable $a$ for the statement "$\sqrt{a}$ represents a positive number" to be true?
* **Answer:** **D. $a$ must be positive.**
* **Explanation:** The principal square root of $0$ is $0$ (which is non-negative, but not positive). If $a > 0$, $\sqrt{a} > 0$.

---

### **Question 3**
* **Problem:** What must be true about the value of the variable $a$ for the statement "$\sqrt{a}$ is not a real number" to be true?
* **Answer:** **A. $a$ must be negative.**
* **Explanation:** The square root of a negative real number yields an imaginary number, which is not a real number.

### **Question 11**

### **Question 17**
* **Problem:** The product of a complex number and its conjugate is always a(n) (1) _______.
* **Answer:** **real number**
* **Explanation:** $(a + bi)(a - bi) = a^2 + b^2$, which is always a real number (specifically non-negative).

### **Question 19**
* **Problem:** Decide whether the given statement is true or false: $\sqrt{-25} \cdot \sqrt{-4} = -10$
* **Answer:** **B. The given statement is true.**
* **Explanation:** $\sqrt{-25} \cdot \sqrt{-4} = (5i)(2i) = 10i^2 = 10(-1) = -10$.

---

### **Question 20**
* **Problem:** Decide whether the given statement is true or false: $(-3 + 6i) - (12 - 5i) = -15 + i$
* **Answer:** **A. The given statement is false. The correct right side of the equation is `-15 + 11i`.**
* **Explanation:** $(-3 - 12) + (6 - (-5))i = -15 + 11i \neq -15 + i$.
