### **Question 1**
* **Problem:** Graph the polynomial function $f(x) = 2x^6$. Then answer parts a and b.
  - **a)** Determine the largest open interval of the domain for which the function is increasing.
  - **b)** Determine the largest open interval of the domain for which the function is decreasing.
* **Answer:**
  * **Graph:** **Choice B**
  * **a):** **Choice A**, **`(0, \infty)`**
  * **b):** **Choice A**, **`(-\infty, 0)`**
* **Graph Equation:** `f(x) = 2*x^6`
* **The Rule:** For $f(x) = ax^n$ with even $n$ and $a > 0$, the graph is symmetric about the $y$-axis, opens upward with vertex at $(0,0)$, decreases on $(-\infty, 0)$, and increases on $(0, \infty)$.
* **Work:**
  - Since $2x^6 \ge 0$ for all $x$ and passes through $(0,0)$ and $(\pm 1, 2)$, the graph is **Choice B**.
  - Moving left to right, $f(x)$ decreases on `(-\infty, 0)` and increases on `(0, \infty)`.

  - **b)** Determine the largest open interval of the domain for which the function is decreasing.

* **Graph Equation:** `f(x) = (-5/6)*x^5`
* **The Rule:** For $f(x) = ax^n$ with odd $n$ and $a < 0$, the graph rises to the left, falls to the right, passes through $(0,0)$, and is decreasing over its entire domain $(-\infty, \infty)$.
* **Work:**
  - The curve passes through Quadrant II, $(0,0)$, and Quadrant IV (**Choice C**).
  - Since $f'(x) = -\frac{25}{6}x^4 \le 0$ for all $x$, $f$ never increases (**Choice B**) and decreases on `(-\infty, \infty)`.

### **Question 3**
* **Problem:** Describe the end behavior of the graph of the polynomial function $f(x) = -8x^3 + 3x^2 - 1$.
* **Answer:** **Choice A** ($\nwarrow$ on the left, $\searrow$ on the right)
* **Graph Equation:** `f(x) = -8*x^3 + 3*x^2 - 1`
* **The Rule:** Odd degree ($3$) with negative leading coefficient ($-8$) $\implies$ rises to the left ($\nwarrow$) and falls to the right ($\searrow$).
* **Work:** The leading term $-8x^3 \to +\infty$ as $x \to -\infty$ and $\to -\infty$ as $x \to +\infty$ (**Choice A**).

### **Question 15**
* **Problem:** The function defined by $f(x) = x^4 + 7x^3 - 24x^2 - 180x$ has the graph as shown. Use the graph to factor the polynomial.
  - *What is the factored form of the polynomial?* $f(x) = \text{______}$
* **Answer:**
  * **Factored Form:** **`x(x - 5)(x + 6)^2`** &nbsp;*(or `f(x) = x(x - 5)(x + 6)^2`)*
  * **Real Zeros / x-intercepts:** **`-6, 0, 5`**
  * **Zero(s) where graph crosses x-axis:** **`0, 5`**
  * **Zero(s) where graph touches and turns around:** **`-6`**
* **Graph Equation:** `f(x) = x^4 + 7*x^3 - 24*x^2 - 180*x`
* **The Rule:**
  - Real zeros correspond to $x$-intercepts of the graph.
  - If a zero has **odd multiplicity** (mult $1$), the graph **crosses** the $x$-axis (at $x = 0$ and $x = 5$).
  - If a zero has **even multiplicity** (mult $2$), the graph **touches the $x$-axis and turns around** (at $x = -6$).
  - Write factors as $(x - r)^m$: factor $x$ (for $0$), $(x - 5)$ (for $5$), and $(x + 6)^2$ (for $-6$).
* **Work:**
  1. From the graph in window $[-8, 8]$ by $[-600, 600]$:
     - At $x = -6$, the curve touches the $x$-axis and turns $\implies (x + 6)^2$ (multiplicity $2$).
     - At $x = 0$, the curve crosses the $x$-axis $\implies x$ (multiplicity $1$).
     - At $x = 5$, the curve crosses the $x$-axis $\implies (x - 5)$ (multiplicity $1$).
  2. Degree of polynomial is $4$; sum of multiplicities is $2 + 1 + 1 = 4$; leading coefficient is $1$.
  3. Complete factored form:
     $$f(x) = x(x - 5)(x + 6)^2$$
  4. Expand to verify:
     $$x(x - 5)(x + 6)^2 = (x^2 - 5x)(x^2 + 12x + 36) = x^4 + 12x^3 + 36x^2 - 5x^3 - 60x^2 - 180x = x^4 + 7x^3 - 24x^2 - 180x \quad \checkmark$$

### **Question 17**
* **Problem:** Find a polynomial of least possible degree having the graph shown (zeros at $-4, 2, 6$ and $y$-intercept $(0, 24)$).
* **Answer:** **`1/2(x + 4)(x - 2)(x - 6)`**
* **Graph Equation:** `f(x) = (1/2)*(x + 4)*(x - 2)*(x - 6)`
* **The Rule:** Each crossing $x$-intercept has multiplicity $1$, so $f(x) = a(x + 4)(x - 2)(x - 6)$.
* **Work:**
  $$f(0) = a(4)(-2)(-6) = 48a = 24 \implies a = \frac{1}{2}$$
  Thus $f(x) = \frac{1}{2}(x + 4)(x - 2)(x - 6)$.
