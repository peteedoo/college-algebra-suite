### **Question 1**
* **Problem:** The inequality $|x - 7| < 2$ can be rewritten without absolute value bars as _______.
* **Answer:** **`-2 < x - 7 < 2`** (Second option in MyMathLab)
* **The Rule:** **LESS-THAND Rule (Conjunction / Sandwich):**  
  If $c > 0$, then $|u| < c \iff -c < u < c$.
* **Explanation:** The distance from $x$ to $7$ is less than $2$, meaning $x - 7$ is trapped strictly between $-2$ and $2$.

---

### **Question 2**
* **Problem:** The inequality $|x - 7| > 2$ can be rewritten without absolute value bars as _______.
* **Answer:** **`x - 7 < -2 or x - 7 > 2`** (Fourth option in MyMathLab)
* **The Rule:** **GREAT-OR Rule (Disjunction / Two Separate Wings):**  
  If $c > 0$, then $|u| > c \iff u < -c \text{ or } u > c$.
* **Explanation:** The distance from $x$ to $7$ is greater than $2$, meaning $x - 7$ lies in the outer tails: either to the left of $-2$ or to the right of $2$.

  * **Part 1 (Rewrite without absolute value bars):** Select **Choice C** and fill in: **`-5 < 2x - 3 < 5`**
  * **Part 2 (Interval Notation):** Select **Choice A** and enter: **`(-1, 4)`**

     $$-5 + 3 < 2x < 5 + 3 \implies -2 < 2x < 8$$

     $$\frac{-2}{2} < x < \frac{8}{2} \implies -1 < x < 4$$
  4. In interval notation: **`(-1, 4)`**.

### **Question 7**
* **Problem:** Solve the inequality: $|2x + 3| \ge 5$.
* **Answer:**
  * **Part 1 (Rewrite without absolute value bars):** Select **Choice A** and fill in: **`2x + 3 \le -5 or 2x + 3 \ge 5`**
  * **Part 2 (Interval Notation):** Select **Choice A** and enter: **`(-\infty, -4] \cup [1, \infty)`**
* **The Rule:** $|u| \ge c \iff u \le -c \text{ or } u \ge c$.
* **Step-by-Step Work:**
  1. Great-or rule: split into two separate outer branches.
  2. **Branch 1 (Left Wing):**
     $$2x + 3 \le -5 \implies 2x \le -8 \implies x \le -4 \implies (-\infty, -4]$$
  3. **Branch 2 (Right Wing):**
     $$2x + 3 \ge 5 \implies 2x \ge 2 \implies x \ge 1 \implies [1, \infty)$$
  4. Combine with union symbol $\cup$: **`(-\infty, -4] \cup [1, \infty)`**.

### **Question 8**
* **Problem:** Solve the inequality: $2|x - 4| > 6$.
* **Answer:**
  * **Part 1 (Rewrite without absolute value bars):** Select **Choice C** and fill in: **`x - 4 < -3 or x - 4 > 3`** (fill in `-3` in first box and `3` in second box)
  * **Part 2 (Interval Notation):** Select **Choice A** and enter: **`(-\infty, 1) \cup (7, \infty)`**
* **Step-by-Step Work:**
  1. **CRITICAL FIRST STEP:** Isolate the absolute value by dividing both sides by $2$:
     $$\frac{2|x - 4|}{2} > \frac{6}{2} \implies |x - 4| > 3$$
  2. Apply Great-or rule to $|x - 4| > 3$:
     $$x - 4 < -3 \quad\text{or}\quad x - 4 > 3$$
  3. Solve each branch:
     * $x - 4 < -3 \implies x < 1 \implies (-\infty, 1)$
     * $x - 4 > 3 \implies x > 7 \implies (7, \infty)$
  4. Combine: **`(-\infty, 1) \cup (7, \infty)`**.

### **Question 12**
* **Problem:** Solve the inequality: $|4x + 1| + 9 < 2$.
* **Answer:** **Choice B: The solution set is $\varnothing$.**
* **The Rule:** For any real expression $u$, $|u| \ge 0$. An absolute value can **NEVER** be strictly less than a negative number!
* **Step-by-Step Work:**
  1. Isolate the absolute value by subtracting $9$ from both sides:
     $$|4x + 1| < 2 - 9 \implies |4x + 1| < -7$$
  2. The absolute value of any real number is always $\ge 0$.
  3. A non-negative value can never be less than $-7$.
  4. Conclusion: There are no real solutions $\implies$ **`\varnothing`** (Empty set).

### **Question 13**
* **Problem:** Solve the inequality: $|8y - 2| \ge -13$.
* **Answer:** **Choice B: The solution set is an infinite set `(-\infty, \infty)`.**
* **The Rule:** For any real expression $u$, $|u| \ge 0$. Since $0 \ge -13$, the inequality is satisfied for **ALL** real numbers!
* **Step-by-Step Work:**
  1. Look at the inequality: $|8y - 2| \ge -13$.
  2. By definition of absolute value, $|8y - 2| \ge 0$ for all real numbers $y$.
  3. Since $0 > -13$, any value $\ge 0$ is automatically greater than or equal to $-13$.
  4. The statement is universally true for every real number.
  5. Conclusion: **`(-\infty, \infty)`** (All real numbers).
